# DIGITAL DZ — Admin & Communauté

## Clés
- Clé du site : `DIGITAL-DZ-2026`
- Clé admin : `DIGITAL-DZ-ADMIN-2026`

## Important
Ce projet reste 100 % statique et sans base de données. Les annonces créées dans `admin.html` sont stockées dans `localStorage` du navigateur de l'administrateur. Elles ne sont donc pas visibles automatiquement par les autres visiteurs.

Pour publier une annonce pour tout le monde, il faut modifier le contenu du site puis faire un commit/push sur GitHub.

La page `community.html` est prête à recevoir le lien d'un canal externe (Telegram, Discord, WhatsApp, etc.). Aucun lien fictif n'est fourni.
