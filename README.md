# DIGITAL DZ V8 — site statique

Cette version ne nécessite ni Supabase, ni base de données, ni compte utilisateur.

## Ouvrir

Ouvre `index.html` dans un navigateur, ou publie tout le dossier sur GitHub Pages, Netlify, Vercel ou un hébergement statique.

## Fonctionnalités
- 25 formations
- 6 modules et 24 leçons par formation
- pages dynamiques formation / leçon / quiz
- missions pratiques
- progression sauvegardée dans localStorage
- favoris
- défi 30 jours
- guides PDF locaux
- liens vidéo et ressources externes
- parcours guidés
- responsive mobile

Les liens externes peuvent être remplacés par tes propres vidéos, PDF ou documents.

## Design
La version finale utilise une identité visuelle « Developer Edition » : dark navy, cyan, violet et rose, accents monospace, cartes interactives et hiérarchie simplifiée.
